# Archived skill copies

Skill packages that ended up bundled into a marketplace item's `files/` by
mistake (the whole skill directory got zipped instead of just the
generated deliverable), preserved here before being stripped out of the
item — in case that embedded copy turned out to be a newer version of the
skill than what's currently installed. Not used by the app at runtime.

## rydr-track-hud-theme

Found inside `data/trackhud-themes/neon/files/rydr-track-hud-theme/`
(the "Neon" theme upload, 2026-08-25). Diffed byte-identical against both
the currently installed skill and its most recent trashed copy on the
machine that produced it — no newer content, archived here anyway per
request before cleanup.
